when 与模式匹配

when 是 Scoop 的多路分支结构。普通分支沿用 Kotlin 的语义，按值、类型或包含关系判断；以 case 开头的分支使用模式，可以嵌套解构 enum、tuple 与 struct，并由编译器检查是否覆盖了所有可能的值。

三种形式

fun load(): Any = "payload"
fun ready(): Boolean = true

fun main() {
    val code = 404
    when (code) {                       // 1. 带 subject
        200 -> println("ok")
        404 -> println("not found")
        else -> println("other")
    }

    when {                              // 2. 不带 subject：每个条件都是 Boolean
        ready() -> println("ready")
        else -> println("waiting")
    }

    when (val item = load()) {          // 3. 在头部声明 subject
        is String -> println(item.charLength)
        else -> println("other")
    }
}
  • 有 subject 时，subject 先求值且只求值一次。
  • 各分支按书写顺序尝试，只执行第一个成立的分支，没有 fallthrough。
  • 分支体可以是表达式、代码块，或 return、throw、break、continue、赋值等单个语句。单行分支以换行结束，同一行写多个分支时用 ; 分隔。
  • when (val 模式 = 表达式) 声明的名称在所有条件、guard 和分支体中可见，离开 when 后失效。头部可以使用不可失败的解构模式，但被匹配的仍是完整的值，而不是解构出的某个部分。

普通分支

不以 case 开头的分支是普通分支：

分支头含义
exprsubject == expr
is T / !is Tsubject 的类型检查；成立时在分支内 smart cast
in expr / !in exprexpr.contains(subject)，适用于区间和任何提供 contains 的类型
c1, c2, …任一条件成立即选中，按顺序短路
else无条件选中；至多一个，必须是最后一个分支
else if cond带 guard 的后备分支，可以有多个，后面仍可以有其他分支和最终的 else
fun classify(n: Int): String = when (n) {
    0 -> "zero"
    1, 2, 3 -> "small"
    in 4..9 -> "digit"
    else -> "large"
}

fun main() {
    println(classify(2) + " " + classify(7) + " " + classify(42))
}
  • 普通分支中的表达式只在执行到该分支时求值，不会预先计算后续分支。
  • 值比较使用 subject 静态类型上的 equals，规则与 == 相同；静态类型为 Any 的 subject 不能用值分支。需要比较引用 identity 时，用不带 subject 的 when { x === y -> … }。
  • 不带 subject 的 when 中不能直接写 is T、in xs 或 case，应写完整的 x is T、x in xs；也不支持 guard，用 && 组合条件。

guard

带 subject 的单个普通条件或 case 模式后可以加 if 条件 作为 guard，括号可选。主条件成立后才求值 guard，guard 为假时继续尝试后续分支。用逗号连接多个条件的分支不能带 guard。

fun describe(x: Any): String = when (x) {
    is String if x.charLength > 3L -> "long string"
    is String -> "short string"
    is Int -> "int"
    else -> "other"
}

fun main() {
    println(describe("hello") + ", " + describe("hi") + ", " + describe(7))
}

case 模式

以 case 开头的分支使用模式语义，模式可以用 val name 引入新的绑定。一个分支只有一个模式，不支持用逗号并列多个模式；同一个 when 中可以混用普通分支与 case 分支。

模式匹配
val name任意值，并绑定为不可变的 name
_任意值，不绑定
字面量：0、-1、2.5、'a'、"text"、true、()与字面量相等的值
V、E.Venum 的单元变体（裸名称只按变体解释，见下文）
V(p1, p2, …)enum 的位置载荷变体，子模式匹配各载荷
V { val f1, f2: p, .. }enum 的命名字段变体；val f1 是 f1: val f1 的简写
(p1, p2, …)tuple，或按字段顺序匹配 struct
S { val f1, f2: p, .. }、{ val f1, .. }按字段名匹配 struct，类型前缀可以省略

子模式可以任意嵌套，并可以使用 .. 忽略其余元素或字段，规则与解构相同。负数字面量可以直接作为模式；其他常量表达式（包括 const val）不是模式。

enum Shape {
    Circle(Double),
    Rect { width: Double, height: Double },
    Empty
}

struct Point(val x: Int, val y: Int)

fun area(shape: Shape): Double = when (shape) {
    case Circle(val r) if r < 0.0 -> 0.0
    case Circle(val r) -> 3.14159 * r * r
    case Rect { val width, val height } -> width * height
    case Empty -> 0.0
}

fun locate(p: Point): String = when (p) {
    case Point { x: 0, y: 0 } -> "origin"
    case { x: 0, .. } -> "on the y axis"
    case (val x, 0) -> f"on the x axis at ${x}"
    case (val x, val y) -> f"(${x}, ${y})"
}

fun describe(pair: (Int, Shape)): String = when (pair) {
    case (0, _) -> "first"
    case (val n, Circle(val r)) if r > 10.0 -> f"#${n}: big circle"
    case (val n, _) -> f"#${n}"
}

fun main() {
    println(area(Shape.Rect(width = 2.0, height = 3.0)))
    println(locate(Point(0, 5)))
    println(describe((2, Shape.Circle(20.0))))
}

绑定与裸标识符

case 模式中的每个绑定都必须显式写成 val name，例如 case val whole、case Some(val value)、case (val first, _)。规则在 tuple、struct 与变体载荷的任意嵌套深度都相同：

  • val name 匹配该位置的任意值，并建立不可重新赋值的局部变量。val 只修饰紧随其后的一个名称，不能写 var、类型标注或 val (a, b) 这样的整组解构；忽略某个值直接写 _，不写 val _。
  • 字段简写 val f1 等价于 f1: val f1，重命名写 f2: val renamed；不带 val 的裸 f1 等价于 f1: f1，不建立绑定。
  • 裸标识符只匹配 enum 变体，既不引用已有的变量或常量，也绝不隐式成为绑定：按该位置 subject 的 enum 类型查找同名变体，命中单元变体就匹配该变体；命中带载荷的变体时报错，要求写出载荷形状 V(…)；没有命中或该位置不是 enum 时是编译错误，并提示绑定应写成 val name。因此拼错的变体名不会悄悄变成兜底分支。
  • Unit 与 () 总是 Unit 字面量。
  • val name 遮蔽该位置实际可用的同名变体时（例如 case val None），编译器给出警告，绑定仍然合法。

要与已有的常量比较，请使用普通分支或 guard：

val LIMIT = 3

fun check(n: Int): String = when (n) {
    LIMIT -> "at limit"                  // 普通分支：n == LIMIT
    case val x if x > LIMIT -> "over"    // val x 是新绑定，用 guard 比较
    case _ -> "under"
}

fun main() {
    println(check(3) + " " + check(5) + " " + check(1))
}
常见错误

case LIMIT -> … 不会与常量 LIMIT 比较：裸名称只能是 enum 变体，这里 subject 是 Int，因此是编译错误。写成 case val LIMIT 则是匹配任何值的新绑定，后续分支永远不会执行。

变体前缀

在模式中，变体名可以省略 enum 前缀，由被匹配值的类型解析；有歧义时写全名 E.V。泛型 enum 的前缀不需要重复写类型实参，类型实参取自 subject。

struct 模式与 tuple 模式要求 subject 的静态类型就是该 struct 或 tuple。对 Any、接口或装箱值，先用 is S 分支做类型检查，再在分支内解构。

分支中的 smart cast

  • is T 成立后，guard 与分支体中可以把 subject 当作 T 使用。
  • 一个分支有多个条件时，只保留所有条件共同建立的类型事实：is A, is B 的分支中 subject 不会同时被视为 A 与 B。
  • 后续分支只继承所有到达路径共同成立的事实。例如无 guard 的 !is T 分支未被选中时，后续分支中 subject 是 T；而 is T if check() 未被选中，可能只是 guard 为假，不能推断 subject 不是 T。
  • 可以收窄的 subject 是不可变局部变量、参数、头部的 val 绑定等稳定值。属性读取每次都可能变化，需要时用 when (val x = obj.prop)。

穷尽性

使用形式是否必须穷尽
任何作为值使用的 when必须
含有至少一个 case 分支的 when（即使作为语句）必须
subject 为 Boolean、enum（包括 Option）或 sealed 类型、作为语句必须
其他 subject 或不带 subject、作为语句不必；没有分支成立时直接继续执行

不穷尽时编译器报错，并给出一个未覆盖的值作为例子，例如 missing pattern Some(-2147483648)。也可以加 else（或 case _）覆盖剩余的值。覆盖规则：

  • enum 的覆盖按变体递归检查载荷：列出所有变体名而载荷没有覆盖完整，仍然不穷尽，例如 Some(0) 与 None 不能穷尽 Option<Int>。
  • tuple 与 struct 的各字段可以由多个分支共同覆盖：(true, _) 与 (false, _) 一起穷尽 (Boolean, Int)。
  • Boolean、Unit、定宽整数与 Char 是有限域；String 与浮点数总是需要通配分支覆盖剩余的值（浮点模式按默认相等匹配，0.0 同时覆盖 -0.0）。
  • 带 guard 的分支不计入覆盖，因为 guard 可能为假；else if 也一样。
  • 普通分支只有字面量与 enum 单元变体这类编译器能确定的值才计入覆盖；变量、函数调用、in 条件与用户自定义的 equals 都不计入。只含单元变体的 enum 用普通分支列出全部变体即可穷尽；整型枚举同样如此。
  • sealed class/interface 按其直接子类型递归展开，is Child 覆盖整个 Child 家族，见 sealed。普通 class 与接口的实现集合是开放的，总是需要 else。
  • 不带 subject 的 when 作为值使用时必须有 else；把最后一个条件写成 true 不算 else。
sealed interface Expr {}
struct Num(val value: Int) : Expr
struct Neg(val inner: Expr) : Expr
struct Add(val left: Expr, val right: Expr) : Expr

fun eval(e: Expr): Int = when (e) {      // sealed：无需 else
    is Num -> e.value
    is Neg -> -eval(e.inner)
    is Add -> eval(e.left) + eval(e.right)
}

fun flags(p: (Boolean, Boolean)): String = when (p) {
    case (true, _) -> "first"
    case (false, true) -> "second"
    case (false, false) -> "neither"
}

fun main() {
    println(eval(Add(Num(2), Neg(Num(5)))))
    println(flags((false, true)))
}
fun f(n: Int): Int = when (n) {     // 编译错误：non-exhaustive when: missing pattern -2147483648
    case val x if x > 0 -> 1           // guard 分支不计入覆盖
    case 0 -> 0
}

结果类型

作为值使用时，每个正常结束的分支以其最后一个表达式作为结果；以 return、throw、break、continue 结束的分支不参与结果合并。存在期望类型时每个分支都必须适配它，否则取各分支的最小共同上界，规则见类型推断。所有分支都不正常结束时，整个 when 的类型为 Nothing。

运行期始终按书写顺序匹配：先匹配模式结构，成功后才求值 guard。穷尽性检查不会改变这一顺序或副作用。
