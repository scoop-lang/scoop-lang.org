熟悉的语法，
原生的性能。

Scoop 是一门静态类型、编译到原生代码的编程语言。它以 Kotlin 的核心语法为基础，加入真正的值类型（struct / enum / tuple）与模式匹配，泛型采用单态化，经 LLVM 生成机器码，并由带分代 Immix GC 的 C 运行时托管内存。工具链自带声明式的原生桌面 UI 框架，同一份代码运行在 macOS、Linux 与 Windows 上。

为什么选择 Scoop

保留 Kotlin 优雅、表达力强的写法，去掉平台包袱，换来可预测的内存布局与原生二进制。

🧊

真正的值类型

struct、带载荷的 enum 和 tuple 都是不可变、无 identity 的值，内联存储、按值复制，数组中连续排布，不再为小对象付出堆分配的代价。

🧩

强大的模式匹配

when 支持 enum 变体、tuple、struct 的嵌套解构、guard 与穷尽性检查，未覆盖的情况在编译期给出可读的反例。

🛡️

没有 null

T? 是 Option<T> 的语法糖，?.、?:、!! 照常可用；T?? 与 T? 是不同类型，语义精确。

⚡

单态化泛型 + LLVM

每组具体类型实参生成专门代码，避免类型擦除带来的装箱；LLVM 后端完成优化并支持跨 Cone 内联。值转换为接口或 Any 时仍按语言规则装箱。

♻️

精确移动 GC

C 运行时提供精确根、写屏障与分代 Immix 收集；原生资源通过 close、use 或 useAsync 确定性关闭，release 块提供尽力而为的回收清理。

🔌

直接的 C FFI

@Extern 绑定 C 函数和全局变量，@CLayout、Ptr<T>、FunPtr<F> 描述原生内存，@Unsafe 明确标出不安全边界。

package examples.testing

import scoop.test.*

@Test
private class CalculatorTests {
    @Test
    fun `division returns a value`() {
        assertEquals(6, divide(42, 7))
        assertTrue(divide(42, 7) > 0)
    }

    @Test
    fun `zero count reports the reason`() {
        val error = assertFailsWith<IllegalArgumentException> { divide(42, 0) }
        assertEquals(Some("count must not be zero"), error.message)
    }
}

原生桌面 UI

随工具链发布的声明式 UI 框架：保留身份的组件、细粒度状态与四套主题，界面由 Skia 自绘，窗口、菜单与托盘使用系统原生实现。

  • 组件即 class：render() 返回不可变的 View，成员 State 被写入时只重绘依赖它的组件，模型与 SwiftUI、Jetpack Compose 相近。
  • 开箱的控件库：按钮、输入框、选择器、表单校验、滚动与虚拟列表、Popover、Dialog、菜单、Toast、Tabs、表格、日历与图表。
  • 四套主题预设：macOS、Material、Fluent 与 shadcn，支持浅色、深色与跟随系统，可定制 tokens 与局部样式。
  • 完整的桌面集成：多窗口、原生菜单与窗框、文件对话框、Dock／任务栏、系统托盘，后台任务与 UI 线程协同。
  • 可测试、可分发：状态测试与窗口测试由 scoop test 运行，scoop bundle 打包为 macOS app、deb／rpm／AppImage 或 NSIS／MSI。

开箱即用的工具链

一个 scoop 命令覆盖新建、包管理、构建、运行、测试、格式化、检查、文档生成与应用打包。

scoop new

新建 Cone

生成可执行或库模板，附带示例测试。

scoop pm

依赖与工作区

解析版本要求，获取 Git 与 registry 源码，用 Cone.lock 固定选择。

scoop run

单文件即跑

直接运行 .scoop 文件，用 //! dep: 声明依赖。

scoop test

内建测试

@Test 标注、断言库与生命周期钩子。

scoop doc

API 文档

从文档注释生成离线、可搜索的文档站点。

scoop build

构建产物

生成可执行文件或 .slib 库，可用 --emit 导出 AST/HIR/MIR/LIR。

scoop fmt / check

格式化与检查

统一源码格式，完成前端检查；支持检查测试源码。

scoop example

离线示例

按主题或关键词查找完整程序、运行步骤与预期结果。

LLDB / VS Code

原生调试

断点、变量、源码行与异常物理栈；可调试应用和 Cone 测试。

scoop bundle

应用打包

生成 macOS app、deb／rpm／AppImage 与 NSIS／MSI 安装包，统一部署资源和原生库。

scoop-lsp / VS Code

语言服务

诊断、补全、跳转、重命名与快速修复；VS Code 扩展提供 Tree-sitter 高亮。

.slib

增量与缓存

预编译库产物，输入未变化时直接复用。

功能完整的标准库

四十多个随工具链发布的预编译库 Cone，从集合、文本、TLS 与 HTTP/2 到 2D 绘图与桌面 UI。

scoop.core / std

核心与基础库

集合、文本、字节、日期时间、UUID。

 scoop.asyncio

异步 I/O

eventLoop() 在 macOS 使用 libdispatch，在 Linux 使用 io_uring，在 Windows 使用 IOCP；scoop.concurrent 提供多线程执行器与 channel。

 scoop.http.*

HTTP 客户端与服务端

HTTP/1.1、HTTP/2、SSE、WebSocket。

 scoop.json

数据与编码

JSON、正则、URL、字符集、压缩。

 scoop.tls / crypto

安全

基于 OpenSSL 的 TLS、摘要与 HMAC。

 scoop.math

数学

标量数学、BigInteger、BigDecimal。

 scoop.cli / log

应用开发

声明式命令行解析、日志 facade。

 scoop.terminal

终端

ANSI 样式、按键事件、readline。

 scoop.ui.*

声明式 UI

组件与状态框架、基础控件库，macOS／Material／Fluent／shadcn 主题。

 scoop.graphics

2D 图形

基于 Skia 的绘图、SVG 与段落排版，可离屏渲染。

 scoop.window

窗口与呈现

原生窗口、事件与菜单，帧调度、动画与区域输入。

 scoop.desktop / tray

桌面集成

Dock 与任务栏状态、Jump List、系统托盘、Lucide 图标。
